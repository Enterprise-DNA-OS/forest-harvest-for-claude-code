# /owner-return

Show the totals, then offer npm run docs -- owner-return for the statement and /draft-owner-update.

```bash
node scripts/harvest.mjs owner-return "<owner>" --month=YYYY-MM
```

Use the configured database. Add `--json` when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record and never send a message.
