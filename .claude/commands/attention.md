# /attention

Lead with the single most urgent item (a late council notice always comes first), then the rest as tables. Offer the matching draft for each.

```bash
node scripts/harvest.mjs attention
```

Use the configured database. Add `--json` when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record and never send a message.
